# FHZL Fleet

Прототип удалённого наблюдения за несколькими 3D-принтерами FHZL в локальной сети. Проекты для Lazarus на Windows.

## Скачать

Нажмите **Code → Download ZIP**, затем распакуйте архив. Также в репозитории есть готовый архив исходников `FHZLFleet-v0.4.zip`.

## Открыть в Lazarus

- На компьютере наблюдателя: `FHZLFleet/Monitor/Monitor.lpi`.
- На каждом управляющем компьютере: `FHZLFleet/Agent/Agent.lpi`.

[Подробная инструкция](FHZLFleet/README.md) · [Результаты проверок и ограничения](FHZLFleet/VALIDATION.md)

Версия 0.4: новый главный экран с выбором принтера по названию, карточками показаний и отдельными журналами. Кнопка **«Управление»** открывает вход по паролю, затем отдельное окно добавления, изменения и удаления принтеров. При первом входе пароль создаётся вами, готового пароля по умолчанию нет.

Готовых Windows EXE в архиве нет — проекты открываются и собираются в Lazarus. Новый интерфейс проверен на настоящих окнах LCL в Linux; запуск в Windows ещё нужно проверить на целевом ПК.

## Диагностика чтения FHZL

[Скачать диагностический считыватель](https://github.com/microsd74-ai/-/raw/refs/heads/main/FHZL-diagnostics.zip). Распакуйте ZIP на управляющем компьютере и запустите `Start-Diagnostic.cmd`. Полученный архив из папки `reports` прикрепите в чат.

[Подробная инструкция](Diagnostics/README.md). Диагностика только читает доступные элементы окна и не отправляет команды принтеру.

## Схема подключения

Agent запускается на компьютере принтера и ждёт соединение на порту 5055. В Monitor откройте **«Управление»**, добавьте имя, IP компьютера принтера и порт. На главном экране выбирайте принтер по названию. IP монитора агенту не требуется; входящий порт разрешается на компьютерах принтеров. Список и имена сохраняются, соединения восстанавливаются автоматически. Агент версии 0.3 совместим с Monitor 0.4.
