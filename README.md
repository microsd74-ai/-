# FHZL Fleet

Прототип удалённого наблюдения за несколькими 3D-принтерами FHZL в локальной сети. Проекты для Lazarus на Windows.

## Скачать

Нажмите **Code → Download ZIP**, затем распакуйте архив. Также в репозитории есть готовый архив исходников `FHZLFleet-v0.3.zip`.

## Открыть в Lazarus

- На компьютере наблюдателя: `FHZLFleet/Monitor/Monitor.lpi`.
- На каждом управляющем компьютере: `FHZLFleet/Agent/Agent.lpi`.

[Подробная инструкция](FHZLFleet/README.md) · [Результаты проверок и ограничения](FHZLFleet/VALIDATION.md)

Готовых Windows EXE пока нет. Сетевая передача проверена на тестовых данных; чтение настоящего FHZL и работа на Windows требуют проверки. Версия 0.3 добавляет текущую строку предупреждений FHZL, температуру, влажность, координаты и конец журнала. Давление каналов и цветные индикаторы ещё не читаются.

## Диагностика чтения FHZL

[Скачать диагностический считыватель](https://github.com/microsd74-ai/-/raw/refs/heads/main/FHZL-diagnostics.zip). Распакуйте ZIP на управляющем компьютере и запустите `Start-Diagnostic.cmd`. Полученный архив из папки `reports` прикрепите в чат.

[Подробная инструкция](Diagnostics/README.md). Диагностика только читает доступные элементы окна и не отправляет команды принтеру.

## Схема подключения версии 0.3

Запустите Agent на компьютере принтера: он ждёт соединение на порту 5055. В Monitor введите IP компьютера принтера и нажмите «Добавить и подключить». Добавьте остальные адреса аналогично. Список сохраняется; есть удаление адресов и автоматическое переподключение. IP монитора агенту не нужен. Обновляются обе стороны; входящий порт разрешается на компьютерах принтеров.
