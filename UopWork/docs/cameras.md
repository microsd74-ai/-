# Камеры Hikvision — v0.3.0

Монитор подключается к RTSP регистратора напрямую, без браузера, ActiveX и установленного VLC. В сборку включён видеодвижок LibVLC x64. Пользователь указал модель **DS-7104NF1/4P(E)**; фактическая работа с этим экземпляром ещё должна быть проверена на месте. Реализованы стандартные Hikvision RTSP-пути; модель сама по себе не подтверждает настройку портов и каналов.

## Настройка

1. Откройте рабочий UopWork.exe, затем «Управление» и введите пароль.
2. Выберите принтер в таблице → «Камеры принтера».
3. Включите показ камер. Укажите **IP регистратора**, а не обязательно IP управляющего компьютера принтера.
4. RTSP-порт по умолчанию 554; введите фактический, если он изменён.
5. Укажите пользователя регистратора и пароль. В переписку пароль отправлять не нужно.
6. Для первых двух каналов укажите 1 и 2. По умолчанию включён дополнительный поток для снижения нагрузки. Если он отключён в регистраторе, снимите этот флажок и проверьте основной поток.
7. Нажмите «Проверить камеры», затем закройте проверку и сохраните настройки.
8. Закройте управление. При выборе принтера на главном экране появятся его две камеры.

Для каналов 1 и 2 используются `/Streaming/Channels/102` и `/Streaming/Channels/202` (дополнительные потоки), либо 101/201 (основные). Для других каналов путь строится аналогично. Камеры разных принтеров имеют независимые настройки.

Кнопка «Развернуть» открывает выбранную камеру на весь экран; «Закрыть · Esc» возвращает обе камеры. Кнопка ↻ переподключает конкретную камеру. Камерный звук отключён и не мешает голосовым тревогам. Цвета видео естественные во всех темах.

## Если изображения нет

Проверьте IP и RTSP-порт, доступность регистратора из сети компьютера монитора, логин/пароль, номера каналов и включён ли выбранный поток. Для проверки можно переключить основной/дополнительный поток. Доступ к веб-странице не доказывает доступность RTSP. При наличии в настройках регистратора отдельного включения RTSP проверьте его; не сбрасывайте настройки регистратора ради подключения.

Видео использует RTSP по TCP. Показ «Видео поступает» появляется после фактического декодирования кадров; при отсутствии новых декодированных кадров 12 секунд видеопоток перезапускается. При ошибке подключения попытка повторяется. Нельзя считать отсутствие картинки признаком остановки печати: показания и голосовые аварии работают независимо.

В демо к настоящим камерам автоматически не подключаемся. Настройку реальных камер выполняйте в рабочем режиме. Настройки камер входят в профиль принтера; изменение его названия/IP агента их сохраняет.

## Учётные данные и файлы

Пароль защищён DPAPI CurrentUser и хранится зашифрованным в settings.json. Он связан с текущей учётной записью Windows; после переноса на другой компьютер/пользователя введите пароль регистратора заново. В форме сохранённый пароль не показывается. Пустое поле при редактировании сохраняет прежний пароль.

RTSP-адрес с логином/паролем формируется только для подключения, не сохраняется как открытый URL и не выводится в журнал аварий или сообщения об ошибках. Сам RTSP в локальной сети не является TLS-шифрованием: используйте доверенную локальную сеть.

Не удаляйте подпапку libvlc и её plugins из распакованной программы. Она нужна даже если VLC отдельно установлен. Компоненты и лицензии описаны в THIRD-PARTY-NOTICES.md.

## Что проверено автоматически

Проверяются совместимость старых настроек, каналы 101/102/201/202, экранирование спецсимволов в RTSP, шифрование DPAPI на Windows, окна настройки/просмотра и загрузка native VLC с декодированием синтетического H.264 ролика. Это не проверка пароля и RTSP конкретного регистратора. Реальные две камеры и обрыв/возврат сети проверяются на месте.
