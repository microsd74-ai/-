# Обновление чтения пустого сообщения об ошибках

Монитор можно обновить отдельно от агента. Положительные ошибки старого агента уже читаются. Но для зелёного «Ошибок нет» требуется обновить два PowerShell-файла на каждом компьютере принтера.

1. Остановите только наш агент. Управляющую программу FHZL и печать не останавливайте.
2. Найдите рядом с агентом прежние ReadPrinter.ps1 и ParsePrinter.ps1. Сохраните их резервную копию.
3. Скопируйте сюда оба файла из этой папки Agent-update, заменив прежние. Другие файлы и настройки IP/порта не меняйте.
4. Снова запустите агент.
5. В мониторе проверьте: если аварийная строка FHZL пуста и её элемент доступен, появится «Ошибок нет»; при аварии — исходный текст. Отдельно проверьте снятие настоящей аварии, когда это произойдёт штатно. Не создавайте неисправность специально.

Обновление только считывает интерфейс через UI Automation; команды управления принтером не отправляет. Пересобирать Lazarus-агент не нужно. Без этого обновления пустая строка старого агента останется «Состояние ошибок неизвестно».

В диагностике установленной версии FHZL аварийная метка QLabel находится после кнопки Exit и разделителя панели mainToolBar. Только успешное чтение пустой метки в этой структуре подтверждает отсутствие аварий. Отсутствующая метка, исключение чтения или незнакомый непустой текст не считаются отсутствием ошибок. В другой версии/локализации FHZL структура может отличаться — в этом случае нужна диагностика, а не подмена неизвестного состояния зелёным.

FHZL показывает одну из нескольких аварий по кругу (например, 1/3, 2/3, 3/3). Монитор запоминает полученные разные сообщения. Подтверждение сохраняется при переключении счётчика. Снятие всех запомненных сообщений фиксируется только при достоверно прочитанной пустой строке: исчезновение одного сообщения из очередного кадра не доказывает его снятие. Поэтому панель содержит полученные ошибки, не гарантированно полный текущий список отдельных аварий.
