# Согласованный план UOP WORK

## 1. Основа C# / WPF — текущий этап

Широкий экран, брендинг UOP WORK, три темы, защищённое управление, сохранение и импорт списка, совместимость с текущим агентом, Windows CI со сборкой и реальными снимками интерфейса. Не считать основу готовым рабочим местом со всеми функциями.

## 2. Достоверные показания и нативный C#-агент

Прямое чтение UI Automation FHZLPrinterManager, подтверждение доступности каждого поля. Состояния: печатает, пауза, завершено, нет связи, ошибка чтения. Отдельный признак успешного чтения пустого списка ошибок. Ничего не нажимать в управляющем приложении.

## 3. Аварии и остановки

- Успешно прочитан пустой список: зелёная галочка и «Ошибок нет».
- Активная ошибка: красный знак с восклицанием и текст FHZL.
- Неизвестность/нет связи не показывать как отсутствие ошибок.
- Отдельно собирать список текущих аварий и историю появления/снятия/подтверждения.
- Отметки аварий видны у невыбранных принтеров; оповещение для всех принтеров.
- Повторяющийся негромкий сигнал и мягкий женский голос: «Внимание! Ошибка в работе принтера!».
- Подтверждение отключает звук, но не снимает красную ошибку. Новая/дополнительная/исчезнувшая и повторно возникшая ошибка включает звук снова.
- 60 секунд без изменения слоя во время подтверждённой активной печати: «Внимание! Печать остановилась!». Не срабатывать на паузе, завершении, потере связи или ошибке чтения. Порог настраивается в админке. Возобновление слоёв снимает предупреждение; новое зависание оповещает заново.
- Готовые WAV для одинакового звучания без Интернета; запись ещё нужно подготовить внешним синтезом речи, здесь генератора голоса не было.

## 4. Камеры

У каждого принтера собственный регистратор Hikvision и две камеры зоны печати с разных ракурсов. Оба потока одновременно; переключаются с принтером. Названия меняются в админке; увеличение по нажатию. Настройки регистратора/каналов/доступа только в управлении. Пропадание видео не останавливает телеметрию. До интеграции нужны модель регистратора и проверка реальных RTSP-потоков. Учётные данные не просить в чате, не хранить открытым текстом в URI/журналах; предусмотреть защищённое хранение Windows.

## 5. Встроенная загрузка заданий

Исходники присланы в «Отправитель стартов.zip»: отправитель и приёмник Lazarus, TCP 45678, папка F:\Start. Использовать как описание существующего поведения, переносить на C#.

Кнопка «Загрузить задание» доступна оператору без пароля. Открывает встроенное окно, назначение автоматически соответствует выбранному принтеру. Перед отправкой явно показать принтер и папку. Общий размер/прогресс, отмена, целостность, подтверждение получения. Принимать во временную папку, публиковать готовое задание только после полной передачи. Адрес и папка приёма — только в админке. Само копирование не является командой запуска печати.

## 6. Рабочее место оператора

Windows 10 Pro, отдельная учётная запись оператора. Полный экран без заголовка и системных кнопок. Автозапуск монитора. Другие программы оператору не нужны. Кнопки перезагрузки и выключения ПК с подтверждением; настройки и выход для обслуживания за паролем. Перед ограничениями ОС проверить независимый вход администратора и восстановление. На Pro не обещать штатный Shell Launcher (он относится к Enterprise/Education); отдельно подобрать и проверить доступные ограничения ОС. Полноэкранность приложения сама по себе не блокирует рабочий стол.

## Оформление

Светлая, тёмная, ретро-терминал в духе Fallout без копирования игровых ассетов. Размещение функций одинаковое; критические ошибки всегда красные со значком/текстом, видео естественного цвета. Тема выбирается без пароля и сохраняется. События подключений убраны с главного экрана, доступны отдельным окном через «Журнал событий» в управлении. Журнал принтера остаётся на главном экране.
