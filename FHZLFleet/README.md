# FHZL Fleet — первая версия

Две программы на Lazarus для Windows. Agent работает на каждом управляющем компьютере принтера. Monitor работает на компьютере наблюдателя и показывает все подключённые принтеры в одной таблице.

Это прототип для проверки на ваших компьютерах. Он не отправляет команды принтеру и не меняет задания печати. Проверка настоящего FHZL в Windows ещё требуется.

## Что уже сделано

- Чтение окна FHZLPrinterManager на основе вашего теста: время начала и окончания, тип окончания (расчётное/фактическое), напечатанные/все слои, длительность.
- Передача по TCP, несколько сборщиков одновременно, русские имена.
- Повторное подключение после потери связи; при отсутствии показателей более пяти секунд таблица помечает их как неактуальные.
- Настройки адреса монитора, порта, имени и уникального ID принтера в окне. Они сохраняются в INI рядом с EXE.
- Журнал изменений состояния в текущем сеансе (последние 200 событий).
- Ошибки чтения: окно не найдено, блок показателей не найден, ошибка доступа.

Ошибки самого принтера (аварии, материалы и т. п.) пока НЕ считываются. Для них нужны примеры соответствующих элементов окна FHZL. Состояние «Показатели получены» означает успешное чтение, а не подтверждение исправности принтера. Длительность берётся из FHZL без дополнительного расчёта. Сборщик видит только одно окно FHZL на каждом управляющем компьютере.

## Открытие в Lazarus на Windows

1. Распакуйте всю папку FHZLFleet в обычную папку с правом записи, например `Документы\FHZLFleet`. Папку `shared` оставьте на месте.
2. На компьютере наблюдателя откройте `Monitor\Monitor.lpi` в Lazarus и нажмите F9. Укажите порт `5055`, нажмите «Запустить».
3. Если брандмауэр Windows спросит о доступе, разрешите его для вашей доверенной частной локальной сети. На компьютере монитора должен быть разрешён входящий TCP-порт 5055 от управляющих компьютеров.
4. На компьютере принтера откройте `Agent\Agent.lpi` и нажмите F9. Управляющая программа FHZLPrinterManager должна быть запущена в том же пользовательском сеансе Windows.
5. В Agent введите IP компьютера наблюдателя, порт `5055`, ID `printer-01` и понятное название, например `FHZL №1`. Нажмите «Запустить».
6. Повторите для остальных управляющих компьютеров, меняя ID (`printer-02`, `printer-03` и т. д.). Два принтера не должны иметь одинаковый ID: одинаковые ID обновляют одну строку таблицы.

Проекты используют стандартные компоненты LCL и библиотеки FPC; дополнительные пакеты Lazarus не нужны. Рекомендуется Lazarus 4.x с FPC 3.2.2, Windows 64 бит. Windows-сборки EXE в этом архиве нет.

Для запуска без Lazarus после сборки копируйте:

- на принтер: `Agent.exe`, `SendPrinter.ps1`, `ReadPrinter.ps1` в одну папку;
- на компьютер наблюдателя: `Monitor.exe`, `ReceiveFleet.ps1` в одну папку.

Используется встроенный Windows PowerShell 5.1. Файлы PS1 должны оставаться рядом с соответствующим EXE. Параметр ExecutionPolicy относится только к запускаемому процессу; системная политика не меняется. Для изменения настроек после запуска закройте и снова откройте программу. Закрытие программы завершает её собственный сборщик/приёмник; FHZL остаётся работать.

Рабочие процессы не запускаются автоматически после перезагрузки: сначала запустите Monitor и нажмите «Запустить», затем запустите Agent на каждом управляющем компьютере и нажмите «Запустить». Сохранённые параметры подставятся из INI.

## Если данных нет

- «Нет связи с монитором»: проверьте IP наблюдателя, одинаковый порт, запущенный Monitor и брандмауэр.
- «Окно FHZL не найдено»: откройте FHZLPrinterManager на компьютере принтера. Сборщик ищет заголовок окна, содержащий это название.
- «Блок показателей не найден»: откройте экран параметров печати. Чтение пока рассчитано на английские поля Finished time, Printed/Total, Start time, Total time из вашего теста.
- «Ошибка чтения окна»: проверьте, что Agent и FHZL работают в одном сеансе и с совместимым уровнем прав. Не повышайте права без необходимости.
- «Процесс остановлен»: посмотрите журнал. Если порт занят, закройте вторую копию Monitor или выберите другой порт в обеих программах.

При сворачивании окна, блокировке сеанса или изменении экрана доступность данных UI Automation зависит от FHZL; это нужно проверить на вашем оборудовании. Первый этап проверки проводите с открытым окном FHZL.

Передача предназначена для доверенной локальной сети: в этой версии нет авторизации и шифрования, поэтому порт нельзя публиковать в Интернете. Программа показывает только те принтеры, от которых хотя бы раз пришло сообщение. После перезапуска Monitor список заполняется заново. Журнал пока не сохраняется на диск.

## Проверки разработчика

- Синтаксический разбор трёх PS1 штатным парсером PowerShell.
- `python tests/network_smoke.py /path/to/pwsh` проверяет настоящие сетевые скрипты на двух сборщиках. Чтение Windows UI Automation заменяется тестовым источником: это не проверка реального принтера.
- Для полноценной проверки Windows: собрать оба LPI, подключить два принтера с разными ID, сравнить показания с FHZL, закрыть FHZL, восстановить его, выключить/включить Monitor и проверить восстановление передачи.

В исходной облачной среде Linux Windows UI Automation и запуск Windows-программ не проверялись. Точный список выполненных проверок приведён в `VALIDATION.md`.
