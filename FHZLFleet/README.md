# FHZL Fleet — версия 0.4

Две программы Lazarus для Windows: Agent на управляющих компьютерах принтеров FHZL и Monitor на компьютере наблюдателя. Monitor сам подключается к агентам по локальной сети.

## Новый главный экран

Вверху — компактный выбор **принтера по названию**, состояние связи и кнопка **«Управление»**. Большая таблица, поля IP/порта и кнопки добавления/удаления с главного экрана убраны.

Для выбранного принтера показываются:

- текущее текстовое предупреждение FHZL и отдельное сообщение об ошибке чтения;
- карточки слоёв, окончания печати, температуры и влажности;
- файл, режим, координаты, время обновления, время слоя и длительность;
- последние строки журнала принтера;
- собственный журнал событий подключения этого принтера.

При переключении принтера меняются все его показания и оба журнала. При потере свежести явно показывается, что значения устарели. «На связи» означает связь с агентом, а не подтверждение исправности принтера. Названия кнопок и компоновка соответствуют согласованному макету; системные кнопки, рамки и шрифты зависят от темы Windows.

## Управление и пароль

1. Нажмите **«Управление»**.
2. При первом входе создайте пароль администратора и повторите его. Минимум 8 символов; готового пароля по умолчанию нет.
3. При последующих входах потребуется этот пароль. Неверный пароль не открывает управление.
4. В отдельном окне введите название, IPv4 управляющего компьютера и порт (обычно 5055), затем нажмите **«Добавить»**.
5. Для изменения выберите принтер в таблице, измените поля и нажмите **«Сохранить»**. Для удаления выберите строку и нажмите **«Удалить»**.
6. Кнопка **«Сменить пароль»** запрашивает текущий пароль, новый и его подтверждение.

Действия сохраняются сразу после успешного нажатия кнопки; обычные пользователи выбирают принтеры на главном экране без доступа к изменению списка. Соединения обновляются автоматически после изменения адресов. Название в мониторе можно задавать независимо от имени агента. Одинаковые названия и одинаковые IP:порт не допускаются.

Настройки сохраняются рядом с Monitor.exe:

- `Monitor.targets.json` — названия и адреса принтеров;
- `Monitor.admin.json` — соль и проверочный PBKDF2-HMAC-SHA256 хеш пароля (210000 итераций), **без открытого пароля**.

В Windows используется системный BCrypt, дополнительные криптобиблиотеки устанавливать не нужно. При повреждении файла пароля вход закрывается с ошибкой, автоматического сброса пароля нет. Сохраните эти два файла при обновлении или переносе программы. Пароль защищает доступ к настройкам внутри приложения; доступ к самим файлам регулируется правами Windows.

## Запуск в Lazarus на Windows

Распакуйте всю папку FHZLFleet в папку с правом записи. Папка shared должна оставаться рядом с папками Agent и Monitor. Рекомендуется Lazarus 4.x / FPC 3.2.2, Windows 10/11. Используются стандартные компоненты LCL и встроенный Windows PowerShell 5.1.

### Компьютер принтера

1. Откройте `Agent/Agent.lpi` и нажмите F9.
2. Введите имя принтера, ID и порт, затем нажмите **«Запустить агент»**. IP монитора не требуется.
3. Разрешите входящий TCP-порт агента (например 5055) в брандмауэре этого компьютера для доверенной частной локальной сети. Сеть обслуживает процесс PowerShell.
4. Откройте FHZLPrinterManager в том же пользовательском сеансе.

### Компьютер наблюдателя

1. Откройте `Monitor/Monitor.lpi` и нажмите F9.
2. Через **«Управление»** создайте пароль и добавьте названия, IP и порты принтеров.
3. Закройте окно управления и выбирайте принтеры в верхнем списке. Подключение и повторное подключение выполняются автоматически.

При запуске без Lazarus после сборки копируйте в одну папку:

- на принтер: `Agent.exe`, `SendPrinter.ps1`, `ReadPrinter.ps1`, `ParsePrinter.ps1`;
- на наблюдателя: `Monitor.exe`, `ReceiveFleet.ps1`.

В пользовательском архиве находятся исходники, **готовых Windows EXE нет**. Закрытие программы завершает её собственный процесс PowerShell; FHZL продолжает работать. Agent после перезагрузки нужно запустить вручную. Monitor автоматически восстанавливает сохранённый список.

## Обновление

С версии **0.3** можно обновить только Monitor и ReceiveFleet.ps1: протокол с агентом совместим. При сборке обновите всю папку исходников, включая shared.

Старый список Monitor.targets.json загружается автоматически, без изменения файла до сохранения в управлении. До получения имени от агента старые адреса показываются как «Принтер 1», «Принтер 2»; затем можно задать постоянные названия через управление. Первый вход в новую админку создаёт ваш пароль.

При переходе с **0.2.x** необходимо обновить обе стороны: начиная с 0.3 агент ждёт подключения, а Monitor устанавливает исходящие соединения. Входящий порт разрешается на компьютерах принтеров.

Один агент допускает до 16 мониторов, Monitor — до 128 адресов. Соединение привязано к IP:порту, поэтому одинаковые ID агентов не смешивают показания.

## Данные и ограничения

Читаются английские поля из ваших диагностических отчётов FHZL: Printed/Total, Start time, Finished time, Total time, Layer seconds, параметры печати, файл и текст верхнего предупреждения, температура, влажность, координаты и режимы. Путь к файлу показывается в том виде, в котором его предоставляет FHZL (он может быть сокращён).

Журнал передаётся ограниченным фрагментом до 20 полных строк и 3000 символов. Используется конец TextPattern и запасной конец ValuePattern. Исторические предупреждения журнала не считаются текущими авариями.

Давление Channel 1/2 и цветные индикаторы TTP/PCC/HDC пока не считываются: в диагностике нет их текстовых значений. Работу UI Automation при свёрнутом окне и заблокированном сеансе необходимо проверить на компьютерах принтеров.

Если соединения нет, проверьте IP компьютера принтера, порт, работающий Agent и входящий TCP в его брандмауэре. Если окно FHZL не найдено, проверьте его запуск в том же сеансе и совместимость уровней прав с агентом.

Передача рассчитана на доверенную локальную сеть: сетевых авторизации и шифрования в прототипе нет. Пароль админки относится к интерфейсу Monitor, а не к сетевому протоколу. Порт агента нельзя публиковать в Интернете.

## Проверки разработчика

- `tests/core_smoke.pas`: сохранение/перенос настроек, русские имена, дубликаты, ошибки ввода, атомарная запись, пароли, смена и повреждение файла пароля. CLI-тест включает UTF-8 режим, используемый Lazarus.
- `tests/gui_smoke.py`: настоящие окна LCL/GTK2 в Xvfb, синтетическая телеметрия; настройка пароля, запрет короткого пароля, отмена создания, неверный/верный пароль, смена пароля, добавление/изменение/удаление, выбор принтера и перезапуск. Требует Linux GTK2-сборку, Xvfb, xdotool и ImageMagick; пользователю Windows эти инструменты не нужны.
- `tests/network_smoke.py`: два агента, редактирование адресов, несколько мониторов, обрывы и перезапуски, повреждённые сообщения и отсутствие постороннего вывода VoidTaskResult.
- `tests/parser_smoke.ps1` и `tests/log_tail_smoke.ps1`: разбор показаний и конец журнала.

Подробные результаты — в VALIDATION.md. Сам новый интерфейс проверен в Linux; нативный запуск Windows и чтение настоящего FHZL новой GUI-сборкой ещё нужно проверить у вас.
