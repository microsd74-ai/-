# FHZL Fleet — версия 0.3

Программы Lazarus для Windows: Agent на каждом управляющем компьютере FHZL и Monitor на компьютере наблюдателя.

**Теперь Monitor подключается к Agent. IP монитора на принтерах вводить не нужно.**

## Запуск в Lazarus

Распакуйте всю папку FHZLFleet в папку с правом записи. Сохраните папку shared рядом с Agent и Monitor.

### На каждом компьютере принтера

1. Откройте `Agent/Agent.lpi` в Lazarus и нажмите F9.
2. Укажите имя принтера, ID (по умолчанию имя компьютера) и порт, например `5055`.
3. Нажмите **«Запустить агент»**. Агент начнёт читать FHZL и ждать подключений.
4. Разрешите входящий TCP-порт 5055 в брандмауэре этого компьютера для доверенной частной локальной сети. Если Windows спросит доступ для PowerShell, разрешайте только нужную частную сеть. Подключения обслуживает процесс Windows PowerShell.

FHZLPrinterManager должен работать в том же пользовательском сеансе. Запущенный агент показывает число подключённых мониторов. IP компьютера наблюдателя агенту не требуется.

### На компьютере наблюдателя

1. Откройте `Monitor/Monitor.lpi` в Lazarus и нажмите F9.
2. Введите **IP управляющего компьютера принтера**, например `192.168.1.112`, и его порт `5055`.
3. Нажмите **«Добавить и подключить»**. В таблице появится строка этого адреса, даже если агент пока недоступен.
4. Добавьте следующие принтеры тем же способом. Настройки каждого адреса сохраняются.
5. Для удаления выберите строку и нажмите **«Удалить выбранный принтер»**. Остальные соединения продолжают работать.

Для каждого принтера используются его IPv4 и порт. Список сохраняется в `Monitor.targets.json` рядом с EXE. При следующем запуске Monitor сам подключается к сохранённым адресам. При обрыве связи выполняет повторное подключение. Один агент допускает до 16 мониторов; Monitor поддерживает до 128 адресов. Принтеры с одинаковым ID остаются разными строками, поскольку строка привязана к IP:порту.

Нажмите на строку принтера, чтобы увидеть подробности и последние записи журнала. Отсутствие свежих данных более пяти секунд отмечается в таблице и подробностях.

## Обновление с версии 0.2.x

**Обновите обе программы и скрипты на всех компьютерах.** Старый Monitor, ожидавший входящие подключения, и новый Agent между собой не соединятся.

- Старый IP монитора в Agent.ini больше не используется.
- Порт, имя и ID принтера сохраняются в Agent.ini.
- Адреса принтеров нужно один раз добавить в новый Monitor.
- Входящий порт теперь открывается на компьютере принтера. Монитор устанавливает исходящие соединения; открывать ему входящий порт не требуется.

При запуске без Lazarus после сборки копируйте в одну папку:

- на принтер: `Agent.exe`, `SendPrinter.ps1`, `ReadPrinter.ps1`, `ParsePrinter.ps1`;
- на наблюдателя: `Monitor.exe`, `ReceiveFleet.ps1`.

Имена PS1 сохранены для удобства обновления: SendPrinter.ps1 теперь является сервером агента, ReceiveFleet.ps1 — клиентом нескольких агентов. Они только передают показания и не выполняют команды управления принтером.

Используются стандартные компоненты LCL, FPC и встроенный Windows PowerShell 5.1. Рекомендуется Lazarus 4.x/FPC 3.2.2. Готового Windows EXE в архиве нет. Закрытие программы завершает её собственный процесс PowerShell; FHZL продолжает работать. Agent после перезагрузки нужно запустить и нажать кнопку вручную; Monitor восстанавливает сохранённый список автоматически.

## Какие данные читаются

- Напечатанные/все слои, время начала/окончания, длительность, время слоя и параметры печати.
- Файл ровно в том виде, как его показывает FHZL (путь может быть сокращён самим FHZL).
- Текущее текстовое сообщение из верхней строки FHZL. Исторические предупреждения из журнала не считаются текущими авариями.
- Температура, влажность, координаты и текстовые режимы.
- Последние строки журнала через TextPattern; если этот способ не сработал — конец ValuePattern. Передаётся ограниченный фрагмент до 20 полных строк и 3000 символов.

Давление Channel 1/2 и цветные индикаторы TTP/PCC/HDC в присланной диагностике не предоставляют текстовых значений. Они пока не читаются. Текст PLC run передаётся как метка, без определения её цвета. «Показатели получены» означает успешное чтение интерфейса, а не подтверждение исправности принтера. Пустое поле показывается как недоступное, без подстановки выдуманных значений.

## Если соединение не устанавливается

Проверьте: правильный IP компьютера принтера, одинаковый порт на агенте и в Monitor, работающий Agent с нажатой кнопкой запуска и правило входящего TCP в брандмауэре **на компьютере принтера**. Если порт занят, закройте вторую копию агента либо смените порт на обеих сторонах для этого принтера.

Если данные не читаются, откройте главный экран FHZLPrinterManager в том же сеансе Windows. Чтение пока рассчитано на английские названия полей из ваших отчётов. При необходимости проверьте совместимость уровней прав FHZL и Agent. Работа UI Automation при свёрнутом окне или заблокированном сеансе зависит от FHZL и требует проверки на оборудовании.

Передача предназначена для доверенной локальной сети. Авторизации и шифрования в прототипе нет; порт агента нельзя публиковать в Интернете. Журнал монитора хранит последние 200 событий текущего сеанса и пока не сохраняется на диск.

## Проверки

`tests/network_smoke.py` проверяет новую схему на реальных сетевых скриптах с тестовым источником вместо FHZL: два агента, недоступный адрес, добавление/удаление, сохранение соединений при некорректном обновлении настроек, несколько мониторов, повторное подключение после перезапуска обеих сторон, фрагментированный UTF-8 и отказ повреждённого сообщения.

`tests/parser_smoke.ps1` проверяет разбор данных. `tests/log_tail_smoke.ps1` проверяет конец журнала и запасной способ. Подробные результаты и ограничения — в `VALIDATION.md`. Windows-интерфейс и новая схема на настоящей локальной сети ещё требуют проверки у вас.
